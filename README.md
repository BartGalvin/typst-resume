# My CV

A [Typst](https://typst.app/) CV with content in YAML. Requires Typst and Make.

```sh
make
```

Builds `output/pdf/Bart_Galvin_CV.pdf`. Use `make watch` to rebuild on changes.

- `cv.yaml` - CV content
- `design.yaml` - fonts, spacing, and page layout
- `cv.typ` - template and section order
