# Bart Galvin's resume

A [Typst](https://typst.app/) resume with content in YAML. Requires Typst and
Make.

```sh
make
```

Builds `output/pdf/Bart_Galvin_Resume.pdf`. Use `make watch` to rebuild on
changes.

- `resume.yaml` - resume content
- `design.yaml` - fonts, spacing, and page layout
- `resume.typ` - template and section order
